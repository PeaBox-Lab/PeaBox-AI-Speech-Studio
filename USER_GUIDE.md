# User Guide

## Start a project

1. Open **Overview → Project Workspace**.
2. Create a project or import project JSON/timeline bundle.
3. Mark frequently used projects as favorites.
4. Use the dashboard or sidebar shortcuts to continue work.

## Prepare production

1. Write the Master Script.
2. Convert paragraphs into Script Editor blocks.
3. Choose providers and voices.
4. Add pronunciation rules and voice presets.

## Generate and assemble

1. Use Speech Generator for a single local render.
2. Use Batch Jobs for resumable provider-aware generation.
3. Inspect WAV files in Audio Quality Lab.
4. Add WAV assets to Timeline Studio and export the production master.

## Review and govern

1. Assign owner, contributors, risk, and workflow state in Governance Center.
2. Add and resolve review comments.
3. Record decisions and approval requests.
4. Review all project records in Activity & History.

## Personalize the interface

Open **Overview → Interface Preferences** to set startup area, navigation density, motion, and dashboard detail. Preferences apply only to this installation.
