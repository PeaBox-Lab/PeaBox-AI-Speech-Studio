# PeaBox v0.06.0 Corporate UI Design
## Navigation architecture
| Area | Screens | Purpose |
|---|---|---|
| Overview | Executive Dashboard, Project Workspace | Portfolio status, project entry, import/export, and master-script management |
| Production | Script Editor, Speech Generator, Batch Jobs, Timeline Studio | End-to-end content preparation, generation, orchestration, and assembly |
| Audio & Quality | Voice Library, Quality Studio, Audio Quality Lab, Transcription Studio | Voice discovery, pronunciation, audio processing, comparisons, and media text |
| Administration | Provider Setup, System Check, Activity & History | Credentials, readiness, diagnostics, and audit-style project records |
| Support | Roadmap & Help | Product status, operating guidance, and next-stage architecture |
## Visual system
- Navy and enterprise-blue shell with cyan accents
- Light neutral workspace background
- Consistent title bars with group, version, and project context
- Bordered white cards with restrained shadows
- KPI cards for executive scanning
- Status pills for project and readiness state
- Section labels with one consistent accent rule
- Consistent spacing, corner radius, and button hierarchy
## Interaction principles
1. The current project is always visible in the sidebar.
2. Navigation reflects the user's workflow rather than the code architecture.
3. Each screen has one purpose, title, and supporting description.
4. Detailed controls remain within the relevant screen rather than appearing globally.
5. The dashboard summarizes state but does not mutate project data.
6. Existing functionality and project formats remain compatible.
