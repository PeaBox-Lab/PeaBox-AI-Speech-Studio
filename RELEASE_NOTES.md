# PeaBox Voice Studio v0.07.2 Release Notes

This release improves daily navigation and continuation workflows after the v0.07.1 responsive UI patch. Users can jump directly to core production screens, reopen favorite or recent projects, and tailor the interface without changing portable project files.

Interface preferences are stored locally and atomically. Corrupt or missing preference data safely falls back to defaults. The dashboard can be Compact, Standard, or Detailed, and the sidebar supports compact density and reduced motion.

All cumulative production, governance, timeline, transcription, provider, and quality features remain available.
